Este projeto foi desenvolvido como parte do **Challenge CarePlus**, focado em otimizar e modernizar a experiência de gestão de saúde, agendamentos e acompanhamento de pacientes através de um portal web responsivo, intuitivo e de alta performance.

---

## 🚀 Funcionalidades Principais

O ecossistema da aplicação foi desenhado para cobrir toda a jornada do utilizador, dividindo-se nas seguintes interfaces e fluxos:

* **🔐 Autenticação Segura:** Portal de login intuitivo para garantir o acesso restrito e seguro aos dados de saúde.
* **📊 Dashboard de Saúde:** Painel principal interativo com métricas e resumos rápidos sobre o estado e histórico do paciente.
* **📅 Gestão de Consultas (Agenda):** Interface dedicada para visualização de consultas marcadas e horários disponíveis.
* **🔄 Reagendamento Flexível:** Sistema para alteração rápida de datas e horários de consultas médicas de forma simplificada.
* **📈 Acompanhamento de Progresso:** Monitorização da evolução de tratamentos e metas de saúde do utilizador.
* **📋 Extrato e Histórico Detalhado:** Histórico financeiro ou de utilizações de procedimentos realizados através do plano.

---

## 🛠️ Tecnologias Utilizadas

A arquitetura do front-end foi construída utilizando as melhores práticas do mercado para desenvolvimento Single Page Application (SPA):

* **[React](https://reactjs.org/):** Biblioteca principal para a construção de interfaces baseadas em componentes reutilizáveis.
* **[TypeScript](https://www.typescriptlang.org/):** Tipagem estática para garantir maior segurança, previsibilidade e menos erros em tempo de execução.
* **[Vite](https://vitejs.dev/):** Ferramenta de build ultra-rápida para um ambiente de desenvolvimento ágil e otimizado.
* **[CSS Modules](https://github.com/css-modules/css-modules):** Estilização escopada por componente, evitando conflitos de classes no CSS global e mantendo o código limpo.

## 💻 Como Rodar o Projeto Localmente

Siga os passos abaixo para clonar o repositório e executar a aplicação na sua máquina:

### Pré-requisitos
Antes de começar, certifique-se de ter instalado o [Node.js](https://nodejs.org/) e um gestor de pacotes (npm ou yarn).

### 1. Clonar o Repositório
```bash
git clone [https://github.com/SimaraSantos/Grupo48_Projeto_Apresentacao_CarePlus_ChallengeProject.git](https://github.com/SimaraSantos/Grupo48_Projeto_Apresentacao_CarePlus_ChallengeProject.git)
2. Entrar na Pasta do Projeto
Bash
cd Grupo48_Projeto_Apresentacao_CarePlus_ChallengeProject
3. Instalar as Dependências
Bash
npm install
# ou
yarn install
4. Iniciar o Servidor de Desenvolvimento
Bash
npm run dev
# ou
yarn dev
O Vite irá disponibilizar um endereço local (geralmente http://localhost:5173/). Abra-o no seu navegador para visualizar a aplicação a rodar em tempo real.
